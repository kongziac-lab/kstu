API 전체를 전수 조사하여 검증했다.

- 표면 출처: 공공데이터포털 `법무부_유학생관리정보 데이터` (data.go.kr id 3069982)
- 원천 시스템: 법무부 산하 출입국·외국인정책본부의 외국인정보시스템(FIMS) 기반
- 데이터 기준일: 2026-06-30, 총 319,147건

## 2. 검증 대상

- 확인 값: 계명대학교 / 전문학사과정 / 20명

## 3. 검증 방법

### 3.1. API 명세 확인
공공데이터포털 OAS 문서(infuser.odcloud.kr)에서 namespace `3069982/v1` 확인.

최신 엔드포인트:
```
GET /3069982/v1/uddi:b851d214-1a5c-4eeb-8566-ab7f1aeaa3db
  → "법무부_유학생관리정보 데이터_20260630"
```

원시 필드 스키마 (4개 문자열 필드):
| 필드 | 타입 | 설명 |
|------|------|------|
| 성별   | string | 남/여 |
| 국적명 | string | 출신 국가 |
| 체류자격 | string | 학사/석사/박사/전문학사 등 |
| 학교명 | string | **교육기관명(문자열)** — 코드가 아님 |

> 중요: 원본 API의 학교 필드는 "학교명" 문자열로 저장된다.
> "교육기관 코드 → 이름 매핑 오류" 가설은 기각한다. 학교명이 이미 이름으로 저장되어 있다.

### 3.2. API 호출 (인증)
- 방식: `?serviceKey={인증키}` query 파라미터
- 인증 실패 예: `{"code":-401,"msg":"인증키는 필수 항목 입니다."}` / `{"code":-4,"msg":"등록되지 않은 인증키 입니다."}`
- 성공: `{"currentCount":N,"data":[...],"matchCount":319147,...}`

### 3.3. 전수 조사
전체 319,147건을 32페이지(perPage=10000)로 페이징하여
`학교명=="계명대학교" AND 체류자격=="전문학사과정"` 레코드만 수집·집계.

결과:

| 국적 | 성별 | 인원 |
|------|------|------|
| 베트남 | 남 | 11 |
| 베트남 | 여 | 7 |
| 몽골   | 여 | 2 |
| **합계** | | **20** |

## 4. 결론

1. 계명대학교 전문학사 20명은 API 원본 데이터에 그대로 존재한다.
2. 대시보드 파이프라인(API → JSON → page.tsx 집계)은 오류가 없다.
3. 4년제 대학(계명대)에 전문학사(D-2-2, 전문대학 과정 비자)가 기록된 것은
   **법무부 원본 데이터의 입력값 신뢰성 문제**이지, 저장소 코드의 문제가 아니다.
4. 동일한 성격의 데이터가 4년제 대학 20곳에 총 73명 존재(계명대 20명이 최다).
